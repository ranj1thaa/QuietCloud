<h1>🌿 QuietCloud</h1>

<p>
A privacy-first journaling, reflection, and vision platform built with modern web technologies.
</p>

<p>
QuietCloud is a thoughtfully designed journaling platform that allows users to write, protect, and selectively share their thoughts in a calm, distraction-free environment.
</p>

<p>
Focused on privacy, emotional safety, and intentional sharing with smooth animations and modern UX.
</p>

</div>

## 🧠 Design Philosophy
<ul>
<li>🔒 Privacy-first architecture (Private by default)</li>
<li>🌿 Calm emotional UX instead of social-feed pressure</li>
<li>👀 Read-only public sharing</li>

## ⚙ Architecture

<ul>
<li>Auth state managed using Context API</li>
<li>Journal data fetched after authentication</li>
<li>Visibility filtering handled at component level</li>
<li>Animations via useGSAP hooks</li>
<li>Carousel rendering for journals</li>
</ul>
